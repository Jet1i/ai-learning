# 第 3 周：Transformer

## 一句话总结
GPT = 词向量 + 位置向量 → 叠 L 个 block（多头注意力 + FFN，各带 LayerNorm 和残差）→ 输出层给词表每个 token 打分 → softmax → 用交叉熵训练“猜下一个 token”。所有要学的参数都在 wx+b 里，唯一的新东西是注意力。

## 核心概念
- **分词器 tokenizer**：把文字切成 token 并编号。按统计合并常见片段（BPE），训练前就定好、冻结，不是参数。编号只是“查词向量表第几行”。不同模型词表不同，模型和分词器成对发布。
- **词向量表 E**：词表大小 × d 的矩阵，随机初始化，是参数。**位置向量表 P**：每个位置一个 d 维向量，加到词向量上（现代模型用 RoPE）。
- **d（维度）**：设计者定的超参数，词向量表跟着 d 走。minigpt 64，GPT-2 768，LLaMA-7B 4096，DeepSeek-V3 7168。
- **自注意力**：`out = softmax(Q·Kᵀ/√d)·V`。Q=我在找什么，K=我是什么，V=我交出去的内容。Wq/Wk/Wv 是参数；Q/K/V 是每句话现算的。注意力权重随输入变，这是和 wx+b 的关键区别。
- **softmax**：eˣ 再除以总和 → 都为正、和为 1；放大差距（“温柔版 max”）；可导。代码里先减最大值防溢出。
- **除以 √d**：点积是 d 个数相加，大小 ≈ √d；不除的话 softmax 饱和成“一个 1 其余 0”，梯度 ≈ 0 学不动。
- **因果遮罩**：右上角设 −∞。训练时所有位置同时猜下一个字，不遮就能直接抄答案；生成时也没有“后面”。BERT 不需要，GPT 必须要。
- **多头**：Q/K/V 的 d 维切成 H 段，各算各的注意力，再**拼接**回 d 维交给 Wo 混合。不增加参数。
- **残差** `x = x + f(x)`：每层只做“补充”不做“重写”；梯度沿“+”直通，不打折。每个子层一个，GPT-2 共 24 个。
- **LayerNorm**：每个子层进门前标准化一次（主干道一路累加，尺度会漂移）。只在支路上，不改主干道。
- **FFN**：d → 4d → d 的 MLP（就是第 2 周写的），每个词自己“消化”，知识主要存这里。
- **block = Transformer 的一层**：`x1 = x + Attn(LN(x))`，`x2 = x1 + FFN(LN(x1))`，先后执行。
- **交叉熵**：loss = −log p(正确答案)。初始 loss ≈ ln(词表大小) 说明初始化正常；loss 下限是数据本身的随机性。
- **temperature**：softmax 前把分数除以 T。低 → 稳定重复（代码/JSON）；高 → 随机有创意。就是 API 里的 `temperature`。
- **参数量** ≈ 12·L·d² + 词表×d（block 里 Wq/Wk/Wv/Wo 4d² + FFN 8d²）。GPT-2：8500 万 + 3900 万 ≈ 1.24 亿。
- **训练 vs 推理**：训练 = 前向 + loss + 反向 + 更新（改参数）；推理 = 只前向，取最后一个位置的概率抽一个 token，循环（用参数）。
- **KV Cache**：推理时把每层旧 token 的 K、V 存起来，新 token 只算自己。因果遮罩保证旧 K/V 不变。用显存换计算；长上下文成本卡在显存。prefill（读入整段，T×T）慢，decode（每步 1×T）快。

## 关键代码
```python
# attention1.py：一行公式
scores = Q @ K.T / np.sqrt(d)
scores = np.where(np.triu(np.ones((T, T)), 1) == 1, -np.inf, scores)   # 因果遮罩
out = softmax(scores) @ V
```
```python
# minigpt.py：一个 block
x = x + self.proj(attention(self.ln1(x)))   # 残差 1
x = x + self.ffn(self.ln2(x))               # 残差 2
# 训练循环还是第 2 周那 4 步
loss = F.cross_entropy(model(x).view(-1, V), y.view(-1))
opt.zero_grad(); loss.backward(); opt.step()
```

## 实验结果
- `attention1.py`：随机权重下“吃”看自己 0.58；去掉 √d 且 d=64 → 每行只盯一个词；加因果遮罩 → 下三角，“我”这行是 1.00。
- `block.py`：4 个头注意力图各不相同；一个 block 3072 参数；d=16→768，参数 ×48² = 7,077,888。**不加位置向量时，“狗咬人”和“人咬狗”里“狗”的输出完全一样**。
- `minigpt.py`（2 层，d=64，10.5 万参数，规则造的句子）：训练前 loss 3.66 ≈ ln(31)=3.43；60 步降到 0.78，之后卡在 ~0.77（“吃”后面 4 种食物各约 0.25，这是数据的随机性）；生成合法句子 100%。
  - L=0（没有 block / 没有注意力）：合法 62%，出现“去超市吃苹果”“在学校。”，因为看不到前面是“去”还是“在”。
  - 8 层**去掉残差**：loss 卡在 3.20，合法 0%；有残差：0.76，100%。
  - temperature 0.3 稳定正确，3 很乱。
- `gpt2.py`（GPT-2 小号，124,439,808 参数）：“我爱吃苹果”被切成 13 个 token（字节级，单个 token 显示为 �）；“The capital of France is”第一名是 " the"（0.085）；中文 prompt 输出“的”+字节碎片+日文“き”——GPT-2 几乎没见过中文。12 头取平均看不出 it→animal，逐头看才能在某些中间层看到。

## 我的提问与解答
**Q：“我爱吃苹果”为什么是 4 个词，不是 5 个字？**
A：代码里手动切的。真实模型用分词器按统计切（BPE），常见片段合成一个 token。API 按 token 计费。

**Q：词向量 / Q、K、V 是怎么确定的？**
A：词向量表和 Wq、Wk、Wv 都是参数，小随机数初始化（约 ±1/√d），靠“猜下一个字”的 loss 反向传播学出来。不能全设 0（对称，所有头永远一样）。Q、K、V 本身不是参数，是 x 乘矩阵现算的。

**Q：词向量的总和也是 1 吗？**
A：不是。只有注意力权重的每一行和为 1。

**Q：QKV 矩阵是随机的，这段代码有什么用？**
A：它是真模型的骨架，计算一样，只差参数有没有训练过（就像 mlp_adam.py 的第 0 步）。

**Q：注意力里 softmax 解决什么问题？**
A：加权平均需要权重为正、和为 1（与句子长度无关），且 softmax 可导，hard max 不可导梯度传不回去。

**Q：位置编码是给每个词加 0、1、2、3 吗？**
A：加的是位置**向量** P[pos]，不是一个数（数字会越来越大盖过词义，信息也太少）。现代模型用 RoPE。

**Q：为什么要残差？（问了两次）**
A：传话游戏：没残差每人重说一遍，传到最后原话没了，梯度也一层层打折；有残差每人拿到“原话 + 批注”，只加批注。实验：8 层去残差完全学不动。

**Q：残差是每隔一层一个吗？** A：每个子层一个，一个 block 两个。

**Q：前向时 x 加注意力结果再加 FFN 结果？** A：对，但有先后：FFN 的输入是已经加过注意力的 x1。

**Q：我理解“前向用 QKV，反向用残差”对吗？**
A：残差是前向就做的加法；反向只是沿前向原路倒着求导，残差的好处体现在反向。

**Q：block 就是一层神经网络吗？**
A：在 Transformer 语境里“层”=block；但一个 block 里有 6 个 wx+b 矩阵，比 MLP 的“一层”大得多。

**Q：为什么要因果遮罩？** A：防止训练时偷看答案；生成时没有后面。

**Q：3×3 是因为 3 个字？全景图是训练吗？**
A：对，T×T；GPT-2 最长 1024×1024，长度翻倍计算 ×4。全景图是训练；推理只前向。

**Q：为什么不直接输出“吃”的结果？长上下文岂不是每次都重算？**
A：训练时每个位置都是一道题；推理只取最后位置，但中间层前面 token 的 K/V 被后面用着。重算问题用 KV Cache 解决（因果遮罩保证可缓存），代价是显存。

**Q：1024 个词猜下一个，softmax 是 1024×1024？**
A：注意力 softmax 在训练/prefill 时是 1024×1024（×头×层），decode 有 KV Cache 只算 1×1024；输出层 softmax 是词表大小。

**Q：为什么两次 LayerNorm？Wo 会膨胀吗？**
A：两个子层各一次。Wo 是 d×d 不膨胀；膨胀在 FFN（4 倍）和输出层（→ 词表）。

**Q：参数怎么算？d 取决于词向量表吗？**
A：参数 = 矩阵里的每个数；≈ 12·L·d² + 词表×d。d 是超参数，词向量表跟着 d 走。

**Q：参数估算具体怎么算？**（以 d=2048、L=24、词表 5 万为例）
A：一个矩阵的参数 = 行×列。Wq/Wk/Wv/Wo 各 d×d ≈ 420 万，共 4d² ≈ 1680 万；FFN 的 W1（d×4d）和 W2（4d×d）共 8d² ≈ 3360 万；一个 block 12d² ≈ 5000 万；×24 层 ≈ 12 亿；词向量表 5 万×2048 ≈ 1 亿（只查一次，不乘 L）；合计 ≈ 13 亿（1.3B）。没有“5万×5万”这样的矩阵。

**Q：所有的 relu 都是拉高 4 倍再回去吗？**
A：不是。ReLU 逐个数操作，不改维度；“先放大 4 倍再压回”是 FFN 的结构（W1 放大、W2 压回），4 倍是原始论文的惯例。GPT-2 用 GELU、4 倍；LLaMA/DeepSeek 用 SwiGLU、约 2.7 倍、3 个矩阵；DeepSeek MoE 拆成多个小专家。

**Q：FFN 升维的意义是什么？**
A：中间 4d 个数每个是一个“探测器”：W1 一行 = 一种模式，ReLU = 亮不亮，W2 一列 = 亮了往主干道加什么；升维 = 更多探测器 = 记更多知识。几何上：低维缠在一起的（圆内外），升到高维加非线性就能分开。只在 FFN 里变宽比整体调大 d 划算（不增大 KV Cache），所以 FFN 占 block 2/3 参数。

**Q：分词器编号固定吗？** A：同一模型固定，不同模型不同。售前：同样的中文在不同厂商切出的 token 数不同。

**Q：12 个头拼回去用了平均？**
A：模型内部是拼接（12×64=768 → Wo）；平均只是我查看注意力时的代码，已改成逐头看。

**Q：有些层 animal 大，和层数有关吗？**
A：有关。底层看表面和邻近词，中层处理语法和指代，高层准备输出；上一层的输出是下一层的输入，多层 = 逐步推理。

## 易错点（小测和提问暴露的）
- ❗ **参数估算**：词表只乘一次 d，不和 L、不和自己相乘。≈ 12·L·d² + 词表×d。
- ❗ **上下文变长，参数不变**。变的是注意力计算量（∝长度²）和 KV Cache 显存（∝长度），而且是推理成本。
- ❗ 残差：说清“去掉会怎样”——信息被重写、梯度打折，深层学不动。
- 手算注意力别漏 softmax 的“除以总和”。
- 残差是前向的加法，不是反向专用的东西。
- Wo 后加的是本 block 的输入（第 2 层起是上一层输出），之后还要过 FFN 才进下一层。
- 词向量 ≠ 注意力权重：只有权重每行和为 1。
- 模型内部多头是**拼接**；“取平均”只是我们看图时的做法。
- 高 temperature 不是“错”，是“更随机”。
