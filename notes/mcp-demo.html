MCP：Agent 和工具之间的“USB-C”

agent.py 里工具是写死的 Python 函数。MCP 把工具搬进独立的 Server 程序，Agent 按统一协议问“你有什么工具”、再“帮我调用这个”。消息格式是 JSON-RPC，走 stdin/stdout（本地）或 HTTP（远程）。逐步点下一步，对照 mcp_agent.py。

Host：你的 Agent

MCP Client（mcp_agent.py 里的 Client）
Agent 循环（和 agent.py 一模一样）

没有 MCP
每个应用为每个工具写一遍对接代码。10 个 Agent 应用 × 10 种工具 = 100 份胶水代码。

    
有了 MCP
工具方写一次 Server，任何支持 MCP 的应用（Claude、Cursor、你的 mcp_agent.py）都能直接接上。10 + 10 份。
