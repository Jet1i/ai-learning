# 第 2 周：神经网络怎么学习

## 一句话总结
训练 = 前向算 loss → 梯度清零 → 反向传播求梯度 → 优化器更新**参数**；反向传播决定“往哪走”，优化器决定“怎么走”。

## 核心概念
- **损失函数 loss**：衡量预测有多错。均方误差 MSE = 平均(err²)，适合预测一个数；大模型预测下一个词用**交叉熵**（第 3 周）。
- **梯度下降**：`w = w - lr × ∂loss/∂w`，往让 loss 变小的方向走一小步。
- **学习率 lr**：步子大小，是**超参数**（人定的，不是模型学的）。太小学得慢；偏大来回震荡；太大发散（loss 爆炸 / nan）。
- **链式法则**：∂loss/∂b = ∂loss/∂err × ∂err/∂b = 2·err × 1。
- **反向传播**：每个数记住“由谁、经什么运算得来”，组成计算图；从 loss 倒着走，每个节点只做“上游梯度 × 局部导数”。
  - 加法：梯度原样传给两边
  - 乘法：传给 a 的梯度 × b 的值（乘“对方”）
- **梯度累加 `+=`**：一个参数被多次使用，各路径的梯度要相加，所以每步要**先清零**（PyTorch 的 `optimizer.zero_grad()`）。
- **神经元**：`激活函数(w1·x1 + w2·x2 + … + b)`。没有非线性激活，叠多少层都等价于一层直线。
- **优化器 optimizer**：SGD 只看当前梯度；Adam = 动量 m（看平均方向，有惯性）+ 自适应步长（除以 √v，每个参数自己的学习率）。大模型训练常用 AdamW。
- **梯度消失**：tanh 导数 1−tanh² 在饱和区接近 0，每层乘一次，传到前面几层几乎为 0。relu 正区导数恒为 1；残差连接也能缓解（第 3 周）。

## 关键代码

for step in range(N):
    loss = forward(...)       # 1. 前向算 loss
    for p in params: p.grad = 0.0   # 2. 梯度清零
    loss.backward()           # 3. 反向传播
    opt.step()                # 4. 优化器更新参数
```

def relu(self):   # 我自己写的，完全正确
    out = Value(self.data if self.data > 0 else 0.0, (self,), "relu")
    def _backward():
        self.grad += (1.0 if self.data > 0 else 0.0) * out.grad
    out._backward = _backward
    return out
```

## 实验结果
- `gd1.py`：lr=0.001 太慢（200 步 w 才到 1.5）；lr=0.3 先冲到 4.1 再来回震荡；lr=0.4 发散。
- 删掉梯度清零：loss 从 0.27 弹回 14.4，w 冲到 4.26。
- `mlp_adam.py`（2→8→8→1，105 个参数，圆内外分类，lr=0.05，150 步）：SGD loss 0.131，Adam 0.054；第 30 步 SGD 88%，Adam 97%。
- lr=0.5：SGD 发散（准确率 28%）；**Adam 不发散**，停在约 90%。
- 去掉 tanh：准确率卡在 72%；加上 tanh 到 98%。

## 我的提问与解答
**Q：SGD 和 Adam 是不同的梯度下降方法吗？**
A：对，都是优化器，只在“用梯度更新参数”这一步不同。`loss.backward()` 算梯度，`opt.step()` 更新。SGD 的 S = Stochastic，本指每步随机抽一小批数据。

**Q：lr=0.5 时 Adam 为什么不发散？**
A：Adam 每步走 `lr × m/√v`，m/√v 大约在 ±1，与梯度大小无关，所以每步最多挪 lr，不会越滚越大；但步子太粗，在谷底来回跳。

**Q：换成 relu 后 Adam 更快更准，为什么？**
A：tanh 有梯度消失，relu 正区导数为 1。但 relu 负区导数为 0，神经元可能“死掉”，所以 SGD+relu 开头反而慢；Adam 会放大小梯度，受影响小。小网络有随机成分，不是定律。

**Q：为什么 loss 用 err 的平方？**
A：不会正负抵消；大错罚得更重；处处可导，且梯度 2·err 在接近答案时自动变小，不会冲过头。|err| 在 0 点有尖角、梯度恒为 1。

**Q：梯度消失后反向传播后面就都变成 0 了吗？**
A：不是正好 0，而是越来越接近 0（如 0.25¹⁰≈0.000001）。受影响最大的是靠近**输入**的前几层。正好为 0 的反而是 relu 负区（“死神经元”）。

**Q：为什么神经元要外面套一个非线性函数？**
A：不套的话两层 = (w2·w1)·x + (w2·b1+b2)，还是一条直线，叠 100 层也白叠。非线性让每个神经元能把直线“折一下”，组合起来能拼出任意边界（万能近似定理）。

## 易错点（小测暴露的）
- ❗ **训练更新的是参数，不是学习率**。学习率是超参数。
- ❗ 训练循环 4 步里别漏了**梯度清零**；“算新的 loss”是下一轮的第 1 步。
- ❗ 手算反向传播要动手练（小测第 1 题跳过了）。
- lr=0.3 不是“没学成”，是震荡后才收敛。
