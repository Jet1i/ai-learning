# 云帆云 云服务器常见问题

## 实例规格
通用型实例的 CPU 和内存比为 1:4，计算型为 1:2，内存型为 1:8。数据库类业务推荐内存型，网站和 Web 应用推荐通用型。

## 无法远程连接
无法通过 SSH 连接 Linux 实例时，请按顺序检查：第一，实例是否处于运行中；第二，安全组是否放行了 22 端口；第三，实例内部的防火墙是否拦截；第四，密码或密钥是否正确。也可以使用控制台的 VNC 远程连接排查。

## 快照与备份
快照是云盘在某个时间点的完整副本，可以用来回滚数据或创建新的云盘。每块云盘最多保留 64 个快照。建议开启自动快照策略，每天凌晨自动备份。

## 地域与可用区
地域之间网络完全隔离，内网不互通。同一地域内的不同可用区之间内网互通，延迟低于 2 毫秒。对高可用要求高的业务，应该把实例部署在同一地域的多个可用区。

## 升级配置
包年包月实例可以随时升级 CPU 和内存，升级需要重启实例才能生效。降低配置只能在续费时操作。
