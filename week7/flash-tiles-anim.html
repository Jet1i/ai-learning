动画：FlashAttention 竖着切、往右走

8 个 token 的三角分数表（行 = query，列 = key，右上被遮罩）。粗线把它切成 2×2 的小块：竖着切 = K/V 每块 2 个 token；横着切 = Q 每块 2 行，分给工人。工人 1（蓝）负责第 1-2 行、然后第 5-6 行；工人 2（橙）负责第 3-4 行、然后第 7-8 行。

工人1 正在算工人2 正在算算完已加进 l、o 并扔掉遮罩（不能看未来）
怎么判断一块要不要算？（看块的编号）
设 Q 块编号 i（第几横条），K/V 块编号 j（第几竖条）：
• j < i：整块都在对角线左下 → 全部算
• j = i：对角块 → 算，但把 key 比 query 靠后的格子遮掉
• j > i：整块都在右上 → 整块跳过，连搬都不搬
所以工人一行行往右走，走到对角块就停：第 i 横条只需要走 i 块。
