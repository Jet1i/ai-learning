# 第 9 周提问记录

## SFT 和 LoRA 是什么关系?SFT 必须一问一答吗?(L1)
- SFT 管"学什么"(模仿标准回答,交叉熵);LoRA 管"改哪些参数"(冻住 W,只训小矩阵 A、B:Wx + B(Ax);4096×4096、r=8 → 65,536 个,约 0.4%)。可以组合:全参 SFT、LoRA SFT、LoRA DPO……
- SFT 不一定一问一答:多轮对话、工具调用轨迹都行。关键是 loss 只算 assistant 部分(user / tool 内容 mask 掉)。
- 没有问答结构的纯文本接着训 = 继续预训练,不是 SFT。

## L2 里"抽到简洁准确"什么意思?打分不需要和其他回答比较吗?(L2)
- 真实 LLM 生成任意文字;玩具里缩成 5 种回答,"抽到"= 这次生成的正好是那一种。
- 比较只在训练裁判时用(L1 两两偏好)。训练好后裁判是 r = w·x,单个回答直接出分(看 4 个特征 × w)。L2 的 6.5 / 9.1 就是 L1 练习 2 算出的分数。
- L2 唯一的"比较"是和 baseline(最近平均分)比,决定推高还是压低。
- 比喻:L1 用"哪道菜好吃"的投票培养评委;L2 厨师每做一道菜评委直接打分,厨师看比平时高还是低。

## KL 绳子到底干嘛?(L2)
- 裁判有盲点(偏爱长度),模型只追分会钻空子(学生发现老师只看字数就凑字数)。
- 规则:某回答现在的概率比 SFT 高越多,每次说它扣越多:β·ln(p/p_SFT)。β=3、废话(SFT 0.1、9.1 分):p=0.1 → 9.1;0.2 → 7.02;0.5 → 4.27。详细准确概率没变 → 6.5。废话涨到一定程度就不划算,停在平衡点(30% 废话)。
- 概率低于 SFT → log 为负 → 变加分,不会彻底忘掉。
- 真实 LLM 不拴绳会退化成骗裁判的怪话、丢掉语言能力;绳子让它只在 SFT 附近小步改进。

## 裁判为什么偏爱长回答?(L2)
- 玩具里是故意设的(TRUE_W 长度 1.0)。现实里叫 length bias:标注员时间紧没空核对事实;长回答看起来认真完整;短而正确显得单薄 → 稍微偏长 → 裁判学到 → RLHF 放大 → 模型越来越啰嗦。
- 同类偏见:附和用户(sycophancy)、自信语气、花哨格式。
- 应对:标注规范、长度惩罚、长度校正评测(AlpacaEval LC)。
- 售前:RLHF 上限取决于标注质量;评测看长度校正后的胜率。

## 标注员是真人吗?(L2)
- 最早是真人(InstructGPT 约 40 个外包标注员做二选一),贵、慢、有偏见;专业题要专家。
- RLAIF:强模型按原则清单判断 A/B(Anthropic Constitutional AI),快便宜但也有偏见。
- 规则校验:数学核答案、代码跑测试,对 1 错 0,没法骗 → L4 DeepSeek-R1 的关键。
- 实际混用。售前:能规则校验的场景(数学/代码/SQL)RL 最便宜最稳。

## "知道终点能不能直接训过去"是什么意思?(L2 → L3 预告)
- RLHF 绕路:偏好 → 裁判 → 生成几千次 → 打分 → RL → 停在 p ∝ p_SFT·e^(r/β)。
- DPO 抄近路:公式倒过来读 → 分数 = β·ln(p_现在 / p_SFT),LLM 自己就是裁判。
- 套 L1 的 loss:β=3,选中 0.3/0.25 → 0.55;没选 0.1/0.15 → −1.22;差 1.77,sigmoid = 0.854 → 往 100% 推。
- 不用裁判、不用采样、不用 RL,显存 2 个模型(PPO 要 4 个)。

## SFT 到底是什么?(L2)
- 三步:预训练(万亿 token 猜下一个字,只会续写,问"怎么退款?"可能接着写更多问题)→ SFT(几万条人写的示范问答,交叉熵模仿,只算助手部分;InstructGPT 约 1.3 万条)→ RLHF/DPO(用偏好调整好坏回答的概率)。
- SFT 模型在第 3 步还是绳子的桩子:复制一份冻住 = 参考模型(rlhf.py 的 REF_P)。
- 比喻:读遍图书馆 → 看客服示范学会接待 → 主管打分让回答更合心意。

## "loss 只算助手那部分"啥意思?(L2)
- 交叉熵:每个位置猜下一个字,loss = −ln p(正确字),取平均。
- 一条 SFT 数据:`用户: 怎么退款? 助手: 点申请退款`。只给助手的字算分:点 0.2 → 1.61、申 0.5 → 0.69、请 0.9 → 0.11,平均 0.80;用户部分(么 1.20、款 2.30)扔掉 = mask。
- 原因:用户问题是给定的题目,不想让模型学着提问,只学怎么回答。
- 和第 3 周比:只换了数据和算分位置,公式没变。

## "看概率比 SFT 涨了多少就能读出裁判的分数"怎么理解?(L2 → L3)
β=3 训练后:废话 0.10→0.301(×3.01),详细 0.25→0.316(×1.26),简洁 0.30→0.321(×1.07),敷衍 0.20→0.040(×0.20),胡编 0.15→0.022(×0.15)。
- 按倍数排序 = 裁判打分顺序。
- 裁判分 − 3·ln(倍数) 每行都 = 5.8(常数),分数整体加减不影响 → β·ln(倍数) 就是裁判分。
- 裁判的分数被写进了模型概率 → DPO:直接要求"人选的涨得比没选的多",不用裁判和 RL。

## "SFT 概率"是啥?SFT 不是微调吗?(L2)
- SFT(动作)= 微调过程;SFT 模型(结果)= 做完 SFT、还没 RLHF 的模型。"SFT 概率" = SFT 模型说出这个回答的概率 = "训练前的概率"。
- 模型每步 softmax 出下一个字的概率再抽 → 同一问题问 100 次答案不同:30 次简洁、25 详细、20 敷衍、15 胡编、10 废话 = REF_P。

## PPO 是啥?(L2)
- Proximal Policy Optimization 近端策略优化 = RLHF 第 3 步实际用的 RL 算法;rlhf.py 是简化版。Policy = LLM;Proximal = 每次只挪一小步。
- 多两样:① clip:每步概率最多变 ±20%(0.30 → 最多 0.36),防止运气好的高分把模型推跑偏;② 价值模型:给每个 token 估"照这样写下去能拿多少分",替代简单平均 baseline。
- clip 比上一步的自己(每步走多远);KL 比 SFT 模型(总共走多远)。
- 4 个模型 → DPO 去掉裁判 + 价值模型;GRPO 去掉价值模型。

## PPO 是用来训练裁判的吗?(L2.5)
- 不是。裁判在 L1 用 −log sigmoid(分差) 训好后冻住;PPO 训练的是 LLM(Policy)。
- PPO 时 4 个模型:LLM ✅ 训练(主角);价值模型 ✅ 一起训练(配角);裁判 ❌ 冻住;SFT 参照 ❌ 冻住。

## 一直提的 SFT 到底在说什么?(L2.5)
- 都是"做完 SFT 后的模型"。时间线:① 预训练 → ② SFT → SFT 模型(会问答)→ ③ 训练裁判(冻住)→ ④ PPO:SFT 模型复制两份,一份继续训练 = LLM(主角),一份冻住 = SFT 参照(绳子桩子)。
- SFT 模型既是 PPO 的起点,也是参照。"SFT 概率" = 冻住那份的概率 = 训练前的概率。DPO 同样两份,但不要裁判。

## PPO 里绳子在哪?(L2.5)
- PPO 不是"调参"(超参数),是改 LLM 权重。
- 一轮顺序:① 生成 → ② 算分(🪢 绳子:裁判分 − β·ln(p/p_SFT),和冻住的 SFT 比,管总距离)→ ③ 分功劳(价值模型)→ ④ 更新(clip:和上一版比,管每批推多猛)。
- 绳子 = 防钻空子;价值 = 分清功劳;clip = 防训练崩。绳子跟 SFT 比,clip 跟上一步的自己比。

## 有绳子了为啥还要 clip?(L2.5)
- 绳子管终点,clip 管每步速度。ppo.py 不限速那组本身拴着绳子(β=3),照样崩 2/8。
- 原因:绳子在算分时算;抽批时废话 p=0.1 = SFT → 扣 3·ln1 = 0;同一批反复更新 10 轮分数不重算,绳子一次都没拉 → 一批内 10% → 91%;下一批才扣分,但已几乎只说废话,拉不回。
- 比喻:绳子 = 最远离家 10 公里;clip = 每分钟最多 1 公里。限速让绳子每步都来得及重新拉。

## clip 的 20% 改的是大模型权重吗?那么多权重?(L2.5,02:34 Jet 自己找到卡点)
- 不是。20% 限的是输出概率。链条:几十亿权重 → wx+b … → logits → softmax → p(准确)。
- 改权重:反向传播算每个权重的梯度,全部一起挪一小步(w −= lr·梯度 / Adam)。
- clip 盯概率:p 0.40 → 0.44(×1.1)继续推;→ 0.49(×1.22 > 1.2)这条数据梯度设 0,不再影响任何权重。= 每条数据身上的开关。
- 真实 LLM 按 token 算 ratio,一个回答几百个 token 就几百个开关。

## 价值模型自己训练的意义?看概率变化有啥用?(L2.5,02:42)
- Jet 自己总结:PPO = 生成 → 和 SFT 比加绳子 → 分功劳 → 概率到 1.2 倍就不用这条,因为生成慢所以要反复用数据。✓
- 价值模型:真实 LLM 没法穷举算 V,只能从数据学:猜"客套后平均 3.0",实际 1.8 → 往 1.8 调,loss = (猜 − 实际)²。猜得准 → 功劳分得准。
- 看概率变化 = clip 开关的依据,量"这批数据已经把模型推了多远";不量就不知道何时停。
- 到 1.2 倍是这一条停,其他继续;整批用满几轮(如 4 轮)后扔掉,生成新一批。

## 价值模型学的"实际分数"从哪来?(L2.5,02:49)
- 来自裁判(减绳子)。裁判只在写完后给完整回答打分;价值模型在写到一半时猜最后能拿几分,拿裁判的最终分当答案学。
- 例:3 个客套开场的回答最终 6、−1、0.4 → 平均 1.8;价值模型猜 3.0 → 往 1.8 调。
- 比喻:裁判 = 期末考试;价值模型 = 老师学期中估分,靠真实期末成绩修正。

## 用功劳改权重,价值模型怎么一步步分的?(L2.5,03:04)
- 回答 `您好 | 亲 | 点申请 | 退款`,最终 5.45。价值模型在每个位置猜 V:3.7 → 3.5 → 1.8 → 4.9 → 真实 5.45。
- 每个 token 功劳 = 写后 V − 写前 V:−0.2、−1.7、+3.1、+0.55,加起来 1.75 = 5.45 − 3.7。
- 改权重:Σ 功劳 × ∂log p(token)/∂权重,一次反向传播;"点申请"推高最多,"亲"压低。然后 clip 按 token 检查。
- 价值模型不是分类,是每个位置打预估分,相邻之差 = 功劳。(真实 PPO 再做 GAE 平滑。)

## 不要玩具,真实 LLM 的 PPO 怎么做?(03:10,Jet 被玩具搞蒙)
准备 4 个模型:π(SFT 复制,训练)、π_ref(SFT 复制,冻住)、RM(SFT + 标量头,冻住)、V(同 RM 结构但每个 token 输出一个数,训练)。
每轮:
1. 生成:512 条提示,π 逐 token 采样(≤512 token),记 logp_old。数据 = 512 × T 的表。
2. 四次前向(无梯度):π_ref → logp_ref;V → V_t;RM 在最后一个 token → R。
3. 每 token 奖励:r_t = −β(logp_old − logp_ref),β 0.01–0.1;最后一个 token 加 R。(绳子按 token 算,玩具里按整句是简化。)
4. GAE:δ_t = r_t + V_{t+1} − V_t;A_t = δ_t + 0.95δ_{t+1} + 0.95²δ_{t+2} + …;整批标准化;价值目标 G_t = A_t + V_t。
5. 同一批用 K=4 轮、分小批:logp_new,ρ_t = e^(logp_new − logp_old);策略 loss = −mean min(ρA, clip(ρ,0.8,1.2)A);价值 loss = mean (V_t − G_t)²;Adam 更新 π 和 V 全部权重(lr ~1e-6)。
6. 扔掉,回到 1。
监控:平均奖励、KL(π‖π_ref)、回答长度。
