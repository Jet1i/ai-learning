奖励模型:把"人更喜欢 A"变成一个分数

配套 week9/reward.py。真实奖励模型 = 一个 LLM 读完回答 + 最后一个 wx+b 吐出一个数。这里把 LLM 省掉,每个回答用 4 个特征代替。

① 两个分数 → 人选 A 的概率

← 试试:概率一点不变,只有"差"有意义

公式就是 sigmoid(差)。差 0 → 50%;差 1.5 → 82%;差 5 → 99%。

② 训练:从一堆"选 A / 选 B"里猜出人心里的 w

标注员心里有一套真实权重(灰色),奖励模型从 0 开始(彩色)。每一步看 2000 对比较,往"让被选中的那个分数更高"的方向挪一点。

loss = −log sigmoid(r_被选 − r_没选)。注意没有 b:两个分数一相减,b 就消掉了。
