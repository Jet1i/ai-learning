RLHF 全流程地图

RLHF 是整套做法的名字(用人类反馈做强化学习)。PPO 是第 ④ 步里实际用来改 LLM 的那个算法。所以准确地说:PPO 是 RLHF 里的一个零件,不是 RLHF 的一种。

一、四个阶段(点每个方块)

模型状态:■ 绿 = 这一步在训练它■ 橙 = 用到它但冻住■ 灰 = 这一步用不到 / 还没有

二、放大第 ④ 步:PPO 的一轮

一个例子从头走到尾:问题"怎么退款?",LLM 写了"客套开场 → 内容准确"。点"下一站"。

① 生成 LLM

LLM 抽一批回答

② 算分 裁判 + 🪢 绳子

裁判打分,绳子扣分

④ 更新参数 ✂️ clip

推高 / 压低,但限速

③ 分功劳 价值模型

把总分分到每一步

按顺时针转一圈:① → ② → ③ → ④ → 回到 ①(LLM 变好一点点,再抽下一批)……重复几千轮

点"下一站"开始。

三、其他路线:替换掉哪一段

DPO(L3)
把 ③ 训练裁判 + ④ PPO 整个换掉,直接拿"A 比 B 好"训练 LLM。
显存:LLM + SFT 参照 = 2 个模型
GRPO(L4,DeepSeek 用的)
还是 RLHF 的流程,但第 ④ 步把 PPO 换成 GRPO:去掉价值模型,同一个问题生成一组回答,彼此比较。
显存:3 个模型(数学 / 代码题用规则打分时,连裁判都不要)
