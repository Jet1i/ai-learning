两轮 DPO 差在哪

同一个 SFT 客服模型、同一个问题「What is the capital of France?」,真 GPT-2 实测。第一轮 loss 更低却没学会拒答,第二轮 loss 高一点却学会了。下面每张图的数字都是用这三个模型(SFT、纯 DPO、修复版)算出来的。

①同一个问题,三种可能的回答

模型面对「法国首都」,可能说出的回答有很多种。我们只盯三种:

拒答(chosen,我们想要的)Sorry, I can only help with ShopX orders, shipping and accounts.
运费答案(rejected,SFT 自己说的)Standard shipping takes 2-4 days. You can track it in My Orders.
胡编(第三种,数据里根本没有)The capital of France is in the form of money, bonds, and money market funds. …

生成是一个 token 一个 token往下走的,每一步贪心地挑概率最大的那个词。所以第一个词基本就决定了它答哪一类:第一个词是 Sorry 就是拒答,是 Standard 就是运费,是 The 就开始胡编。

②第一个词:三个模型各选了谁

③DPO 的原理:它只看「差距」

DPO 对每一对数据只算一个数:差距 = rchosen − rrejected,其中 r = β × (logπ − logπref)。loss 和「推力」都只由这个差距决定:

loss = −ln σ(差距) 推力 = σ(−差距) 梯度 = β × 推力 × [ 推高 chosen − 压低 rejected ]

拖动差距,看 loss 和推力怎么变:

0.693
推力 = σ(−差距)(训练开始时是 0.5)
0.500

关键:公式里没有任何一项要求「chosen 要排第一」。只要 chosen 比 rejected 高出足够多,推力就趋近 0,DPO 就停手了。

④第一轮:概率被挪到了哪里

三种回答的整句 log 概率(越靠右越可能被说出来,0 = 100%)。圆点是三个模型:

S = SFT(训练前)纯 = 第一轮 纯 DPO修 = 第二轮 修复版
回答SFT纯 DPO修复版第一轮发生了什么
拒答−95.15−44.29−1.82涨了 50.9,可还是太低
运费答案−5.02−17.34−10.07被压低 12.3,让出概率
胡编−39.69−33.00−43.96没人教它,也涨了 6.7

第一轮时运费答案的整句概率(−17.3)其实还是三者里最高的,但它的第一个词 Standard 只剩 2.4%。贪心是一步一步选的,第一步就选了 The(23.8%),后面顺着 The 一路编下去。rejected 让出来的概率,没去 chosen,而是流到了第三种回答。

⑤逐 token 看拒答那句:第一个词卡住了

每格下面的数 = 模型在那个位置给这个 token 的概率,颜色越深越高。整句 log 概率 = 16 个格子的 ln 加起来。

⑥修法 1:再加一项 SFT loss,专门把 chosen 推到第一

loss = −ln σ(差距) + α × ( −平均每个 token 的 ln p(chosen) ) α = 1.0(Llama 3 做 DPO 时用 0.2)
DPO 那一项新加的 SFT 项
它要什么chosen 比 rejected 高出足够多chosen 的每个 token 都接近 100%
每个 token 的推力β × σ(−差距),差距大了就 ≈ 0∝ (1 − p),p 没到 1 就一直推
「法国首都」的 Sorry第一轮停在 3.1 × 10⁻⁷,推力只剩 0.0018p 很小时推力 ≈ 1,一直推到 0.967

这一项就是第 3 周、L0 用过的交叉熵,只是只对 chosen 算。它补上了 DPO 缺的那句话:「chosen 不光要比 rejected 好,还得高到能被说出来。」

⑦修法 2:加了 SFT 项又冒出「误拒」,再补一类数据

只加 SFT 项时,拒答这句话被推得太猛,有些网店问题也开始答 Sorry。于是给每道网店题再加一对:正确答案 ≻ 拒答(该答的别拒)。四次真跑的结果:

配置无关问题拒答网店题答对说明
纯 DPO(第一轮)0/64 → 3loss 0.002,行为没变
+ SFT 项,α = 0.26/64 → 33 道网店题被拒(误拒)
+ SFT 项 α = 0.2 + 「别拒」对0/64 → 4别拒压过了拒答
+ SFT 项 α = 1.0 + 「别拒」对(第二轮)5/64 → 4现在的默认

修复版对网店题「When does my parcel get here?」的第一个词:Standard 99.99%,Sorry 0.01%,没有误拒。还错的 2 道网店题(取消订单、改地址都答成退款)在 SFT 阶段就错了,DPO 这次没碰它们。

⑧总结:两轮到底改了什么

第一轮 纯 DPO

  • 数据:无关 → 拒答好于乱答(12 对);网店 → 正确好于答错类别(12 对)
  • loss:只有 −ln σ(差距)
  • 结果:差距拉开了(6.32),但主要靠压低 rejected;Sorry 反而更低,概率流向胡编

第二轮 修复版

  • 数据:再加网店 → 正确好于拒答(12 对,该答的别拒)
  • loss:−ln σ(差距) + 1.0 × chosen 的 SFT loss
  • 结果:Sorry 0.967,排第一;拒答 5/6,网店题不掉

售前一句话:DPO 擅长在模型已经会的几种说法之间调偏好;要它学一句从没说过的话,得先 SFT,或在 DPO 里加 SFT 项。上线前要在没见过的问题上同时测「拒答率」和「误拒率」,loss 再低也不算数。
